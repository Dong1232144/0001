# 枪战风云 · GUN BLITZ

单文件 HTML5 俯视角竞技场射击游戏。纯 Canvas 手写渲染，**零依赖、无需安装、无需联网**，双击即玩。

## 立即游玩

- 在线试玩：<https://dong1232144.github.io/0001/gun-blitz.html>
- 游戏门户页：<https://dong1232144.github.io/0001/>
- 本地运行：下载 `gun-blitz.html`，用浏览器打开即可

## 操作

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` | 移动走位 |
| 鼠标 | 瞄准方向 |
| 左键 | 开火射击 |
| `R` | 装填子弹 |
| `1` `2` `3` `4` | 切换武器 |
| `P` / `Esc` | 暂停 |
| `M` | 开关音效 |

## 机制

- **连杀倍率**：连续击杀累积，最高 `x2.5`，受伤或断连清零
- **掉落系统**：红心回血 `+28 HP`，黄箱补弹，靠近自动磁吸
- **波次推进**：逐波刷新，波次越高敌人越硬越多
- **打击反馈**：击退、震屏、命中火花、冲击环、死亡爆散、低血脉动警示
- **程序化音效**：全部由 Web Audio 实时合成，不含任何外部音频文件

## 技术说明

整个游戏是单个 HTML 文件，约 47 KB，内部结构：

- 固定逻辑分辨率 `1120 × 700`，画布随窗口等比缩放
- `requestAnimationFrame` 驱动，时间步进做钳制（`clamp(dt, 0, 1/30)`）防止掉帧与异常时间戳污染物理
- 狙击枪走**瞬时射线**判定并支持穿透，其余武器为**逐帧分步推进**的弹丸，避免高速穿模
- 对象池化的粒子系统，尸体贴花上限 130 条防内存增长
